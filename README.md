# Payment Operations Reconciliation Engine

Автоматизированный инструмент сверки транзакционных логов системы с реестрами банков-эквайеров.

## Решаемые задачи

- Детекция зависших платежей (`PENDING_STATUS`) для авто-выдачи услуг.
- Поиск расхождений в суммах списания (`AMOUNT_MISMATCH`).
- Выявление неучтенных банковских списаний (`NOT_IN_DB`).
- Блокировка потенциального фрода и оказания услуг без оплаты (`UNPAID_SERVICE`).
- Автоматическое распределение приоритетов (`CRITICAL`, `HIGH`, `MEDIUM`) и формирование инструкций по исправлению (`AUTO_UPDATE`, `ADJUST_BALANCE`, `BLOCK_USER`).

## Как работает

Проект сопоставляет:
- внутреннюю таблицу транзакций;
- банковскую выписку;
- статусы и суммы платежей.

На выходе формируется CSV-отчет с аномалиями и приоритетами для дальнейшего устранения.

## Файлы проекта

- `script.py` — Python-скрипт сверки файлов и генерации CSV-отчётов.
- `sql_reconciliation.py` — SQL-скрипт сверки внутри СУБД (SQLite/PostgreSQL).
- `internal.csv` — внутренние транзакции.
- `bank.csv` — банковская выписка.
- `discrepancies_report.csv` — результат сверки.

## Запуск

```bash
python script.py
python sql_reconciliation.py
```

## Пример проблем, которые выявляет система

- `PENDING_STATUS`
- `AMOUNT_MISMATCH`
- `NOT_IN_DB`
- `UNPAID_SERVICE`

## Цель проекта

Ускорить операционную сверку, уменьшить ручной аудит и снизить риск финансовых потерь и мошенничества.
